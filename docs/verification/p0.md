## Task 05 — 身份、资源策略与目标准入

| 项 | 命令 | 结果 |
|---|---|---|
| identity | `cargo test -p conex-core --test identity` | 3 passed |
| policy | `cargo test -p conex-core --test policy` | 6 passed |
| target_policy | `cargo test -p conex-core --test target_policy` | 6 passed |

- `IdentityMap` 以完整带来源的 `IdentityKey` 精确映射；不同 issuer 的同名 sub 映射到不同 Principal，未知主体返回 unauthorized，不产生默认用户。
- `StaticPolicy` 默认拒绝，principal/tenant/endpoint/action/resource 全部匹配才授予；`replace_rules` 原子替换并单调递增版本。段边界按 `resource_within` 判定，`team` 不匹配 `team-private`；单文件权限不能授权子树扫描。
- `TargetPolicy` 只校验已解析地址：默认拒绝私网/loopback/link-local/未指定；显式 `allowLoopbackHttp` 才允许 loopback 明文；混合 DNS 结果只选获准地址并固定为单一拨号地址；拒绝 userinfo、路径、动态 fixedPath。
