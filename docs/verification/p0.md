## Task 03 — CIDv1 raw/SHA-256

| 项 | 命令 | 结果 |
|---|---|---|
| Rust CID 测试 | `cargo test -p conex-proto --test cid` | 3 passed / 0 failed |
| TS 独立实现 | `bun test sdk/typescript/tests/cid.test.ts` | 1 passed / 0 failed |
| 全量 | `cargo test -p conex-proto`、`bun test sdk/typescript/tests` | 13 + 6 passed |

- `cid_for_raw` 生成 CIDv1/raw/SHA-256 小写 base32；黄金字节与 `conformance/vectors/p0/cid.json` 一致。
- `parse_cid` 拒绝非 raw codec、非 sha2-256、错误摘要长度与尾随字节；不同文本基归一到二进制比较。
- TS 用 `multiformats` 独立计算同一向量，不依赖 Rust 输出自证。
