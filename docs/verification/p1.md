### 产出

- 失败向量：`RecoveryLevel::Persistent` 在 P1 demo 强制降级为 `InProcess`（返回 UnsupportedRecovery，advertised 不一致直接拒）；binding 不匹配 → BindingMismatch；过期 → LeaseExpired → session_lost；path traversal 拒绝。

### 已知偏差（待 P1-02 WSS + P1-10 接入）

- 跨进程 Session 恢复（host 重启后复活）属于 P4；当前 P1 仅承诺窗口内网络重连。
- `session/resume` / `session/renew` / `session/close` MethodContract 注册 + WSS 帧绑定在 P1-02 / P1-10 接入。

## P1-02 — WSS 引导（demo slice，state machine）

| 项 | 命令 | 结果 |
|---|---|---|
| 单元测试（hello/ready 状态机 + 失败向量） | `cargo test -p conex-core --lib transport_ws` | 12 passed |
| P0 + P1-01 + P1-06 + P1-07 + P1-08 + P1-03 + P1-02 完整门禁 | `cargo xtask check` | all steps passed |

### 产出

- 新增 `crates/conex-core/src/transport_ws/mod.rs`：`ServerHandshake` + `ClientHandshake` 状态机，`AwaitingHello → AwaitingReady → Ready`；`conex/hello` → 服务端生成 `negotiationId` 一次性 → `conex/ready`；`HelloRequest`/`ReadyRequest` 使用 camelCase + prost `Plane` 走 `plane_serde` 自定义适配器（小写 wire / SCREAMING_SNAKE prost 反序列化）。
- 失败向量：业务帧早于 `ready` → `EarlyBusiness`；profile 不匹配 → `UnsupportedProfile`；plane 不匹配 → `PlaneMismatch`（`plane_mismatch`）；`negotiationId` 不匹配 → `NegotiationIdMismatch`；`conex/hello` 在 `AwaitingReady` 状态时再发 → `MalformedEnvelope`；`conex/ready` 在 `Ready` 之后 → `EarlyBusiness`；超 64 KiB → `BufferExceeded`；UnknownMethod；未指定 plane → `MissingPlane`。
- 两个 Profile（`conex-jsonrpc2-wss-v1`、`conex-protobuf-wss-v1`）都完成 hello/ready happy-path 验证。

### 已知偏差（待 P1-10 / 真实 WS 集成）

- 真实 WS frame I/O（axum/hyper 接入、握手超时取消、resume/超窗 reset 联动）属于 `conex-transport-ws`；本 demo slice 仅交付状态机。
- 业务帧的"协商编码切到 Profile 选定编码"由 transport crate 在 `conex/ready` result 后切换；本状态机仅放行，不再做内容解码。
