# P0 runbook

P0 是可嵌入/独立运行的 broker 只读主干：Rust host + JSON-RPC/HTTP + fs 与 HTTP catalog provider + TypeScript consumer。

## 1. 环境

```bash
./scripts/bootstrap-toolchain.sh     # Rust + protoc 到 .toolchain/（gitignored）
source .toolchain/env.sh
bun install
```

版本 pin 见 `tools/codegen.lock.json`。

## 2. 生成与测试

```bash
cargo xtask generate                  # .proto -> Rust / TS / JSON Schema
cargo xtask generate --check          # CI 用，检测生成漂移
cargo xtask conformance --vectors conformance/vectors/p0   # Rust/TS 共享向量
cargo xtask check                     # 完整 P0 门禁
```

## 3. 入站 token

入站只接受管理员预注册的静态 bearer；配置里存 SHA-256 摘要，不存明文：

```bash
printf %s "dev-token-a" | sha256sum
```

把摘要填入 `[[tokens]] token_hash`。每个 token 绑定 principal、tenant 与 audience；OIDC/JWT 未在 P0 验证，不接受。

## 4. 出站凭据

`[[endpoints]]` 的 `credential_backend = "env:NAME"` 或 `"file:/abs/path"` 指向安装配置，调用方无法提供路径；file 必须为属主私有普通文件。凭据仅在对端身份与授权确认后解析。

## 5. 启动

开发（loopback 明文，仅本机）：

```bash
cargo run -p conex-host -- examples/p0/host.toml
```

生产必须提供 `[tls] cert/key`；`allow_loopback_http=true` 只允许 loopback 监听。SIGTERM/SIGINT 触发 10 秒优雅退出。

## 6. 用 TypeScript 调用两个 provider

```ts
import { ConexClient } from "@conex/sdk";

const client = await ConexClient.connect({
  url: "http://127.0.0.1:8787/rpc",
  tokenProvider: async () => "dev-token-a",
  requires: ["source/list", "source/read", "source/search"],
});

// 成功
const read = await client.read("notes-local", { resourceId: "hello.md" });

// 拒绝：无权限/未知资源
try { await client.read("notes-local", { resourceId: "secret.md" }); }
catch (error) { console.error(error.code, error.message); }

// 部分失败：searchMany 逐目标保留结果
const results = await client.searchMany([
  { endpointId: "notes-local", input: { root: "", query: "conex" } },
  { endpointId: "catalog-work", input: { root: "", query: "conex" } },
]);

client.close();
```

## 7. provider 配置

- `source-fs`：`root` 指向受限目录；只读 `.md`/`.org`，单文件 256 KiB。
- `source-http-catalog`：`origin`/`fixed_path`/`ca_pem`/`expected_server_name`；整分区授权，静态 JSON 无服务端过滤。

## 8. 日志与秘密

审计文件 0600、有界容量；不写 token/Secret/私钥。访问日志不得包含 query 中的凭据。示例配置只含占位摘要，不得提交真实凭据。
