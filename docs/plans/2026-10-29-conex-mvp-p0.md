### Step 2：建立无模型元数据探针

- [ ] 新增 `scripts/probe-agent-protocols.py`，使用下列完整脚本。它只创建自己的临时工作目录和进程、发元数据请求，不发 prompt、turn/start 或模型请求；只输出脱敏后的成功标志，不打印状态正文和 stderr。

```python
#!/usr/bin/env python3
import asyncio
import json
import tempfile


async def exchange(argv, request, request_id, accepted, workdir):
    process = await asyncio.create_subprocess_exec(
        *argv, cwd=workdir, stdin=asyncio.subprocess.PIPE,
        stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.DEVNULL,
    )
    ready = False
    try:
        assert process.stdin is not None and process.stdout is not None
        process.stdin.write((json.dumps(request) + "\n").encode())
        await process.stdin.drain()
        async with asyncio.timeout(30):
            while True:
                line = await process.stdout.readline()
                if not line:
                    raise RuntimeError("protocol exited before metadata response")
                try:
                    frame = json.loads(line)
                except (ValueError, UnicodeDecodeError) as error:
                    raise RuntimeError("non-JSON protocol frame") from error
                if not isinstance(frame, dict):
                    raise RuntimeError("protocol frame is not an object")
                ready = ready or frame.get("type") == "ready"
                if frame.get("id") == request_id:
                    if not accepted(frame):
                        raise RuntimeError("metadata response rejected")
                    return {"ok": True, "ready": ready}
    finally:
        if process.returncode is None:
            process.terminate()
        try:
            await asyncio.wait_for(process.wait(), 5)
        except asyncio.TimeoutError:
            process.kill()
            await process.wait()


async def main():
    with tempfile.TemporaryDirectory(prefix="conex-agent-probe-") as workdir:
        omp = await exchange(
            ["omp", "--mode", "rpc", "--no-session", "--no-extensions",
             "--no-skills", "--no-rules", "--no-context-files", "--no-lsp",
             "--cwd", workdir],
            {"id": "metadata", "type": "get_state"}, "metadata",
            lambda frame: frame.get("type") == "response"
            and frame.get("command") == "get_state"
            and frame.get("success") is True,
            workdir,
        )
        if not omp["ready"]:
            raise RuntimeError("OMP did not announce ready")
        codex = await exchange(
            ["codex", "app-server"],
            {"id": 1, "method": "initialize", "params": {
                "clientInfo": {"name": "conex-probe", "version": "0.0.0"},
                "capabilities": {"experimentalApi": False},
            }}, 1,
            lambda frame: "error" not in frame
            and isinstance(frame.get("result"), dict)
            and "userAgent" in frame["result"],
            workdir,
        )
        print(json.dumps({"omp": omp, "codex": {"ok": codex["ok"]}}))


if __name__ == "__main__":
    asyncio.run(main())
```

```sh
python3 scripts/probe-agent-protocols.py
```

预期：退出 0，输出 OMP `ok/ready=true` 和 Codex `ok=true`。超时/退出/畸形响应非零，不用返回空成功掩盖问题。禁止为这个脚本增加只验证 mock 回显的永久测试；真实 exchange 输出就是此元数据路径的 smoke。脚本清理仅作用于自己创建的两个进程。

## 3. Task P0.2：隔离真实生命周期探针

此任务需要可用的现有模型授权与额度。缺少时先完成 P0.3/P0.4 的可达部分并记录精确缺项，不导出凭据、不自动改 provider、不以 fixture 替代 live。当前文档同步不执行本任务。

- [ ] 按 P0.1 schema 编写短生命周期驱动，仍只操作临时 Workspace 与自己创建的会话。启动参数不得关闭沙箱/审批，不连接用户正在运行的实例进行试验。
- [ ] 每个后端创建新会话，发送“只回复 CONEX_PROBE_OK，不访问工具”，观察完整消息序列与执行结束信号；继续该会话验证历史和身份稳定。
- [ ] 发起足够长但无外部副作用的输出任务，中途发取消。记录请求接受、消息结束、执行静止的顺序；取消太晚则重跑该独立场景，不把自然完成当取消成功。
- [ ] 在临时目录内触发一次真实人工交互并拒绝，记录拒绝后状态；使用实际支持的审批/提问机制，不通过改成 yolo/never 达到不阻塞。若模型未触发所需事件，记录未覆盖，不能改写为通过。
- [ ] 后端事件能提供 subagent 时，在隔离任务中派生只读子任务并记录父子标识；不支持或不可查询时明确能力为不可用/未知。MVP-P3/P4 仍需验证其所支持的真实关系路径。
- [ ] 自有进程里主动断开协议消费者，再重连/读取历史，确认能恢复哪些快照、增量、审批状态；审批断线若后端行为未定义，Conex 采用待核对/失效而非自动同意。
- [ ] Codex 自己创建一个供探针使用的外部 app-server，再连接/断开消费者，确认消费者退出不终止服务，最后由原创建者回收。OMP TUI 附着只调查独立路径，不复制当前活跃会话。

驱动只留消费者可见的最小场景代码和脱敏输出；P0 的一次性调研脚本完成后清理，后续 Adapter live 验收由 P3/P4 正式入口承接，避免永久维护两套协议客户端。

退出：每个结论有实际事件或明确版本文档，未知项的产品处理已确定。元数据成功不能替代这些真实生命周期结果。

## 5. Task P0.4：冻结私有运行与安全契约

新增 `docs/contracts/private-runtime.md`：

- [ ] 定义本地 Scope、托管/外部所有权、应用包 schema、允许的实现注册、显式依赖与导出；本地生命周期、中心发布、连接分别定义状态和关闭行为。
- [ ] 固定客户端/节点认证、凭据获取/存放/轮换/撤销、节点侧验证、操作范围、授权有效期和时钟容差。选择已安装/受维护库支持的格式；不自制签名算法。
- [ ] 固定浏览器认证边界：HttpOnly/Secure/SameSite 会话及一次性/短期 WSS 票据、Origin/CSRF、直连目标允许列表；Emacs 使用专用凭据，不复用浏览器 cookie 文件，不把 bearer 放 URL。
- [ ] 定义 direct-only/relay-allowed 的目录、调用、订阅、同步、持久化限制，以及派生数据导出的显式批准；中心不接受任意代理地址。
- [ ] 固定离线授权窗口与到期行为；本地撤权立即生效，中心分区撤权不承诺即时。端点不可达与授权失效分开。
- [ ] 固定中心/节点 SQLite 所有权、schema 迁移/备份、崩溃恢复、正文/凭据日志禁令；派生/缓存不能偷偷改变存储边界。
- [ ] 写出两条路由的可信上下文传递、取消目标固定、换代、超时/结果未知和不自动重放；客户端不能通过 payload 提供有效 Principal。
- [ ] 写出负路径矩阵：匿名、错误主体、过期、重放票据、错误 Origin、伪造上下文、错误目标、越权方法、direct-only 转发/落盘、撤权、慢消费者、断中心。

退出：P2/P5 无需猜测身份、关闭顺序或授权格式；真实公网部署仍需独立授权，不能因为本契约完成而开放现网。
