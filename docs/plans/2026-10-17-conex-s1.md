# S1 双向能力与 SDK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 在真实中心进程与独立 TS/Rust 节点之间完成双向模块注册、调用、取消和状态订阅，并通过 S1 A01–A12 验收。

**Architecture:** 延续现有 JSON-RPC/WSS 握手与静态批准机制，通用能力按契约和注册代次路由；SDK 既提供又消费能力。HTTP 仅消费目录、调用及取消，工作台和插件生命周期不进入本切片。

**Tech Stack:** Rust/Tokio、现有 WebSocket/HTTP 依赖、TypeScript/JS/Bun、Protobuf + prost/pbjson/ts-proto、现有 cargo xtask。

