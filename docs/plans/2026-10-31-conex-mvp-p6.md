# Conex MVP-P6 指标与关系 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` or `subagent-driven-development`，按任务执行；先读 [MVP 架构基线](../design/2026-10-29-conex-private-platform.md)（实体/关系/指标节）与 [Agent 领域契约](../contracts/agent-domain.md)。本文件是待执行计划，不是交付证据；不自动部署或提交。

**Goal:** 节点侧真实服务器指标采集、实体关系/Tags/Workspace 投影与分别查询；为 A09 提供可独立消费的实体/关系数据，为 A10（视图）与 A14（组合）提供输入。

**Architecture:** 采集与关系投影是节点内领域模块，像普通模块一样提供自身契约并经正常发布导出，不是中心功能也不内嵌适配器后端。先快照后更新；节点断开投影过期而不改业务状态。关系/标注/指标的唯一结构源仍是 proto；不引入图数据库，投影存 agent-domain SQLite。

**Tech Stack:** `sysinfo`（节点 crate 现有依赖，P5 已用于进程身份；版本锁定不变，按需扩展 features 至 disks 等采集项）、rusqlite `=0.41.1` 不变、entities.proto/agent_domain.proto 生成链。指标首版目标是实际部署 Linux 节点；实现走跨平台 API，不支持的平台/指标显式标注，不伪造数据。

## 2. P6.1 指标采集

- [ ] CPU 使用率按相邻采样差计算（累计计数不直接当比例）；内存/磁盘读真实值；每样本携带 sampledAtMs、platform、quality；不支持的指标省略并说明，不填 0 冒充。
- [ ] 采样间隔与保留上限来自批准配置；保留量、时间窗有界（基线数据边界条款），prune 不破坏在用游标/查询语义。
- [ ] 量纲核对：与本机 OS 数据源核对 CPU%/bytes/时间与边界；**Linux 节点真实采样核对是本包 live gate**——本机 macOS smoke 只证明代码路径与量纲换算，不算 Linux 证据；暂无 Linux 节点时该 gate 随 P9 两机验收执行，本包保持未完全关闭状态。

## 3. P6.2 实体与关系投影

- [ ] 关系字段：source=backend/config/user、quality=current/stale/historical/unknown、observedAtMs；实体引用为稳定 ULID `{nodeId,id}`；Workspace 绑定节点身份。
- [ ] Tags 是标注：所有权分 node/user（私有运行数据边界），不充当权限；status 属于实体本体。
- [ ] 描述关系（运行于、关联 Workspace、参与会话、派生执行、用户标注）与能力绑定（谁经哪个契约使用哪个提供者）分开建模与存储；绑定查询需单独授权，依赖关系不是生命周期所有权。
- [ ] subagent 关系仅在后端有 ID/父执行证据时 source=backend（数据来自 P3/P4 写入的关系）；无信息标 unknown，不从聊天文本猜测。

## 4. P6.3 查询与生命周期

- [ ] 描述关系查询沿用 `agent/relationships/list`；能力绑定走新增独立操作，分页/页 token/权限语义与契约 §4 一致；关系可见不授予执行内容权限，不经关系线扩大授权。
- [ ] 用户删除关系只删标注/投影行，不取消后端执行、不影响生命周期所有权。
- [ ] metrics/relations 模块以自身普通契约导出（normal capability），供第三消费者组合读取/订阅；A14 组合闭包在 P9 验收。

## 5. P6.4 传播与过期

- [ ] 先快照后更新；节点断开/采样超时 → 投影 quality=stale，不把后端业务强制改 failed。
- [ ] 断连/重连 smoke：重连后续采新样本；过期窗口内旧样本仍可查但标 stale；不静默清空历史样本。

## 6. 运行与退出

真实节点采样并与 OS 数据源核对量纲、时间与边界；一次断连/重连 smoke。完成后运行：

```sh
cargo test -p conex-agent -p conex-agent-domain
cargo xtask e2e --suite private-entities
cargo xtask check
```

退出：A09 所需实体/关系可从独立消费者查询（来源与未知边界正确、Workspace/Tags/subagent 可见）；指标样本有界、可核对、断连过期语义正确。Linux live 核对未执行前不宣称本包完全关闭，缺口记入证据页。
