# conex 落地页演示内容

这一份内容是**合成样例**，用于让访客在真实运行中的落地页上走通真实的
`source/list`、`source/read`、`source/search` 与 `/content` 读取路径。

它不来自任何真实主机，也不代表任何真实数据。

## 你正在看的是什么

- 落地页由一个真实的 `conex-host` 进程提供，不是静态截图
- 你的浏览器只与这个 Host 通信；演示内容通过它授权后按需返回
- 每一个目录项、每一次文本与图片渲染都走同一条受授权的读取链路

## 可以试的事情

1. 在「内容浏览」里点开任意文件，查看文本、图片与归档的受限预览
2. 在「读取服务」里手动执行 `source/list` / `source/read` / `source/search`，
   观察返回的原始 JSON
3. 下载任意二进制文件并比对字节——未知类型不会经过 UTF-8 转换
4. 打开 `/llms.txt`，查看同一站点的机器可读说明

## 边界

该演示为只读：页面不提供 shell、写文件、blob 提交或 Agent 注册入口。
被拒绝的路径会以明确错误返回，而不是静默返回空结果。
